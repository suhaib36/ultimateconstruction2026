# Unlimited Construction – Mobile Web Application

> Professional construction management mobile web application for **Unlimited Construction**, owned and operated by **Nancy Paramo** (California License #1040445, Class B General Contractor).

Reference website: [https://unlimited-construction.com/](https://unlimited-construction.com/)

---

## Overview

Unlimited Construction is a centralized mobile-first web application designed to help Nancy Paramo and her construction team manage jobsites, schedules, daily field logs, estimates, client communications, and change orders—all with a dedicated, secure **Homeowner Portal** for clients.

### Key Highlights

- **Pure Mobile Web Application**: Responsive edge-to-edge layout on mobile devices, tablets, and desktop displays with persistent mobile top and bottom navigation bars. No phone bezel/frame wrappers.
- **Contractor App (Nancy Paramo & Team)**:
  - **Today / Overview**: Quick metrics, active jobs, urgent change orders awaiting sign-off, schedule visits today, and quick field actions.
  - **Jobs / Projects**: Searchable project directories, status filters, and comprehensive project workspaces (Overview, Tasks/Punch list, Photos, Change Orders, Documents, and Client Chat).
  - **Field Logs**: Daily jobsite reports featuring live weather stamps, work completed today, work planned next, and photo upload simulation.
  - **Schedule**: 14-day calendar picker and timeline of city inspections, concrete pours, site visits, and material deliveries.
  - **More**: Leads & Estimates (with one-tap *Convert to Project*), Change Order management, Clients directory, Crew directory, Document library, and CSLB #1040445 settings.
- **Homeowner Portal (Client Side)**:
  - **Project Switcher**: Toggle between active clients (Elena Martinez, David Johnson, Robert Williams, Sandra Anderson, Carlos Garcia).
  - **My Project**: Progress gauge, permit numbers, and direct contact card for Nancy Paramo.
  - **Progress**: Chronological daily field reports and a full-screen **Photo Lightbox**.
  - **Schedule**: Milestone roadmaps and city inspection status.
  - **Documents**: City-approved permits, architectural plans, and agreements with **Preview Modal** and simulated download.
  - **Approvals**: Transparent itemized cost breakdowns with an **Electronic Signature Modal** and **Request Revision Modal** (linked directly to the chat).
  - **Live Chat**: Direct messaging with Nancy Paramo featuring 3 quick prompt chips and realistic simulated auto-replies with typing indicator.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/suhaib36/ultimateconstruction2026.git

# Navigate to project directory
cd ultimateconstruction2026

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

### Build for Production

```bash
npm run build
```

The production assets will be built to the `dist/` directory.
